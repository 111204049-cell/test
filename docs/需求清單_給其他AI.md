# 專案需求：個人專屬學習系統（名稱暫定「腦圖書館」）

請從零開始設計並實作這個系統。以下只列出我的需求，技術與服務由你自行選擇與說明理由。請使用繁體中文與我溝通，介面也用繁體中文。

## 一、基本條件
1. **跨平台**：要有網站，也要有手機 App（iOS 與 Android），電腦前或通勤都能無縫學習。我想先個人試用，滿意再上架商店。
2. **高隱私**：這是我私人的學習空間，不是公開影音平台。A 帳號絕對看不到 B 帳號的任何資料。
3. **使用規模**：先當作 5 人以內，主要是我自己。
4. **成本**：長期零成本或極低成本。我有 Google Cloud 免費試用額度 $9,534，2026/12/31 到期，試用結束後不想產生高額帳單。我也有 GitHub 帳號。
5. **介面**：好看、使用順暢，目標是「大家看到都覺得 wow，會得獎的那種」。
6. **語言**：先只做中文。
7. **新技術**：請主動提出更新、更厲害的做法，不要只給保守方案。

## 二、功能需求
1. **影片**：能儲存並播放大量教學影片。影片可能是我直接上傳，也可能是我貼 YouTube 連結。要避免影片的儲存與流量產生高額費用。
2. **分類管理**：資料要能分類，例如「AI」「藝術」「大學」。大學底下還要分「大幾」，大幾底下才是各堂課。藝術、AI 學習等類別不是這個結構。我上了很多不同的課程。
3. **文字學習資料**：能建立並儲存文字類的學習資料。
4. **匯入檔案**：可以直接匯入檔案來學習，格式包含 PDF、Word、PPT、網頁、圖片（圖片需要文字辨識 OCR）。
5. **筆記**：可以記筆記。
6. **螢光筆與標註**：文件資料可以畫螢光筆等標註。
7. **點單字翻譯**：點擊單字會出現小視窗翻譯，主要是英文翻成中文。
8. **單字集**：可以收集單字成單字集。
9. **字典**：要有一個額外的字典。
10. **複習功能**：
    - 學科複習與單字複習都要有。
    - 複習的間隔曲線要符合網路上關於大腦記憶與吸收新知的方法。
    - 可以結合 AI。
11. **首頁 AI 小助手入口**：首頁有一個像 AI 小助手的入口。我看到相關的學習資料時可以隨手丟給它（文字、連結、截圖、檔案），它會自己幫我分門別類放好。
12. **AI 供應商**：我目前用的 AI 有 Claude、ChatGPT、Muse、Gemini。如果串進系統有幫助就用。這個入口之後可能會做成外掛（plugin）。
13. **開源資源**：請到 GitHub 搜尋你覺得安全、而且對達成以上需求有幫助的開源專案，並告訴我你選它的理由。

## 三、我不是工程師
我是產品負責人，負責定義需求、測試與決定方向。需要我在網頁主控台或終端機操作的地方，請用白話一步一步說明。
