## 2. 核心目標

### 2.1 跨平台
- 要同時有「網站」和「手機 App（iOS／Android）」，在電腦前或通勤都能無縫學習。
- 你明確說「手機我要 App 版本」。
- 目前做法：先做可安裝的網頁 App（PWA），在手機「加到主畫面」就像 App。原生 App 上架（App Store／Google Play）等試用滿意後再做。
- **狀態：部分完成**。PWA 已完成並部署，手機尚未實測安裝。原生上架未開始。

### 2.2 高隱私、個人化
- 只有本人能存取，A 帳號絕對看不到 B 帳號的資料。
- 做法：Google 登入加 Firestore 安全規則，每人只能讀寫自己的 `users/{uid}`。
- **狀態：部分完成**。程式與規則已部署，但登入流程目前有問題（見第 8 節），所以還沒有實際驗證過隔離。

### 2.3 長期零成本或低成本
- 要能撐過 GCP 免費試用結束，不產生高額帳單。
- 已確認的事實：你的試用額度是 $9,534，**2026/12/31 到期**。之前另一個 AI 說的「每月 $10 開發者福利」我無法確認。
- 做法：架構設計成在免費的 Spark 方案就能運作，影片放你自己的 Google Drive，不放 GCP。
- 預算警告：建議你在 Google Cloud 設定預算警告（例如 $1 就通知）。**狀態：待你操作**。
- **狀態：部分完成**。目前只用 Hosting、Auth、Firestore，都在免費額度內。

### 2.4 介面要求
- 好看、設計順暢，希望「大家看到都覺得 wow，會得獎的那種」。
- 你看過六種方向（液態玻璃、新粗野主義、極光夜幕、瑞士網格、貼紙手帳、深空立體），偏向 **1 液態玻璃** 和 **4 瑞士網格**，但說「還不到我的點」。
- 你想要我多提供選擇和「更厲害的新技術」。
- 目前做法：液態玻璃質感加瑞士大字體加單點紅色，淺色與深色模式跟隨系統。
- **狀態：部分完成**。第一版已做，但你還沒說哪裡不夠。需要你回覆：不夠華麗？不夠柔和？顏色不對？或貼你喜歡的 App 截圖。

## 3. 功能需求

### 3.1 科目與分類管理
- 要能分類，例如 AI、藝術、大學，因為你上很多不同的課程。
- 大學底下分大幾，大幾底下是哪堂課。
- 藝術、AI 學習等類別不是這種結構。
- 做法：資料夾樹，每層自己命名，深度不限。
- **狀態：已完成**（新增、重新命名、刪除；手機版為抽屜加底部分頁）。
- 尚缺：拖曳移動、排序。

### 3.2 學習資料（文字）
- 能建立與儲存文字類學習資料。
- **狀態：已完成**（筆記編輯、自動保存、字數統計）。
- 尚缺：富文字（粗體、標題、清單）、搜尋。

### 3.3 匯入檔案學習
- 可以直接匯入檔案：PDF、Word、PPT、網頁、圖片（要 OCR 文字辨識）都有可能。
- 預計採用：PDF.js、mammoth.js（Word）、Mozilla Readability（網頁）、Tesseract.js（OCR）。PPT 需另外評估。
- **狀態：未開始**。

### 3.4 螢光筆與標註
- 文件資料要可以畫螢光筆等等。
- 預計採用 react-pdf-highlighter-extended（基於 PDF.js，標註資料可存進資料庫）。
- **狀態：未開始**（目前只支援純文字筆記）。

### 3.5 筆記
- 要可以記筆記。
- **狀態：已完成**（見 3.2），與檔案並排筆記未做。

### 3.6 點單字翻譯與單字集
- 點擊單字會有小視窗翻譯，主要是英文到中文。
- 要能收集單字集。
- **狀態：已完成**。
  - 筆記「閱讀」模式：點任何英文單字顯示中文、音標、英文釋義。
  - 「編輯」模式：選取文字按「查詢」。
  - 可修改卡片背面後一鍵加入單字卡，自動附上筆記中的例句。
  - 已收集的字在閱讀模式有紅色底線。
- 注意：翻譯來自免費的 MyMemory，品質我**沒有看過真實結果**，可能不夠準。

### 3.7 額外字典
- 要有一個額外的字典。
- 現況：用 Free Dictionary API 加 MyMemory 線上查詢。
- 規劃：離線字典 ECDICT（SQLite，含考試標籤），轉成繁體。
- **狀態：部分完成**（線上版）。離線字典未開始，需先確認 ECDICT 授權。

### 3.8 複習功能
- 要有學習複習功能，複習曲線要符合大腦吸收新知的研究。
- 學科複習和單字複習都要有。
- 做法：FSRS 演算法（ts-fsrs，v6），單字和學科問答共用同一套卡片。
- 已有：新增卡片、翻面、四個評分（再一次、困難、良好、簡單）、顯示各評分的下次間隔、鍵盤 1 到 4、20 分鐘學習窗口、到期數徽章。
- **狀態：部分完成**。
- 尚缺：編輯卡片、依科目篩選複習、複習統計與連續天數、AI 自動出題。

### 3.9 影片
- 能處理與播放大量教學影片。
- 你可能「直接上傳影片」或「貼 YouTube 連結」。
- 策略 A（已確定）：影片放用戶自己的 Google Drive，資料庫只存連結；只用 `drive.file` 權限加 Google Picker，避免 Google 的敏感權限審核。
- YouTube：只存連結與標題。
- 規劃：Whisper 在瀏覽器內轉逐字稿，之後可點字幕查單字、做重點筆記。
- **狀態：未開始**。
- 已知限制：Drive 內嵌播放器沒有倍速、章節等自訂功能，大檔案可能需等待處理。

### 3.10 首頁 AI 小助手（portal）
- 首頁有一個像 AI 小助手的入口，你看到相關學習資料可以隨手丟給它，它自動分門別類放好。
- 輸入：文字、連結、截圖、檔案。
- 你目前用的 AI：Claude、ChatGPT、Muse、Gemini。若串進 App 有幫助就用，之後可能變成 plugin。
- 已決定：**第一版只接 Gemini**（有免費層，截圖中可建立 Gemini API 金鑰）。Claude 與 ChatGPT API 要付費，之後視需要再加。
- 設計原則：做成獨立模組，輸入文字、連結、檔案，輸出「分類、摘要、單字」的 JSON，與介面分離，方便日後做成瀏覽器擴充或其他外掛。
- Gemini 免費層額度自 2026 年起不再公開固定數字，需到 AI Studio 查看，要做好超額降級。
- 呼叫金鑰的安全：若要保護金鑰，需用後端（Cloud Functions，需要綁卡的 Blaze 方案）；個人用可先讓每人自己填金鑰。**待你決定**。
- **狀態：未開始**。

### 3.11 開源資源搜尋
- 你要我在 GitHub 搜尋我覺得安全、對實現想像有幫助的內容並告訴你。
- 已提出：ts-fsrs、react-pdf-highlighter-extended、ECDICT、Transformers.js 加 Whisper、Tesseract.js、mammoth.js、Mozilla Readability。
- 提醒：我只做了初步篩選，沒有逐一審查程式碼，使用前請你自己確認授權與維護狀態。
- **狀態：持續進行**。

## 4. 技術架構（已決定）

| 層面 | 選擇 |
|---|---|
| 前端 | React 18、TypeScript、Vite，PWA（vite-plugin-pwa） |
